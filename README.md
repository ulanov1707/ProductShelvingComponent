Replicated Shelving System — Unreal Engine
This project implements a replicated shelving system, inspired by mechanics from games like Supermarket Simulator, where products are automatically placed onto shelves.

LINK :
https://www.youtube.com/shorts/G4OtRtcnTx4

🪄 Features:
✅ Shelving Component — Manages interaction between the carried product box and the shelves.
✅ Product Crate — A box that can be grabbed and dropped; contains the product itself, with properties like name, amount, type, and allowed placement areas (e.g., shelf, refrigerator, table).
✅ Product Slot — Represents a single shelf slot; you can use it as a child actor for your own refrigerators, stands, or tables, and products can then be placed onto it.
✅ Stackable Products — Supports stacking items like Coca-Cola cans or boxes on top of each other, if applicable.

⚙️ Customization:
You can freely adjust shelf sizes to your needs — the math behind the system (based on shelf bounds) will handle the placement automatically.
